# Theia Application Project
## Overview
This repository contains all documentation and deliverables related to THEIA, a mobile application developed by Team JD for Cpt_S 484: Software Requirements. Project Theia is an indoor navigation app designed to for the visually impaired by providing users assisted navigation, obstacle detection, and emergency assistance using smartphone sensors.
## Repository Contents
### Phase 1 Deliverables
- Phase 1 Presentation Slides outlining Initial Project sSenarios and Prototype Plans.
- Phase 1 Presentation Video on Slides.
